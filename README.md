# MONSTERA AI — T1 Skeleton

Next.js 15 App Router, TypeScript strict, Tailwind, shadcn configuration, Drizzle, Fly.io and CI scaffolding only.

```bash
corepack enable
corepack pnpm install
corepack pnpm typecheck
corepack pnpm lint
corepack pnpm build
```

`app/api`, `db`, and `components/ui` are intentionally empty or placeholders. No provider implementations, database tables, auth, billing or logging are included.
